# ربات تیتر «ذره‌بین» — ایران اف‌تی‌وی

ویدیو را برای ربات بفرست، با دکمهٔ «عمودی / افقی» جهتش را بگو، بعد تیتر را به صورت پیام متنی.
- عمودی: قالب اول (ویدیو تمام‌قاب).
- افقی: ویدیو به سه تکه تقسیم می‌شود؛ تکهٔ وسط ویدیوی اصلی با رنگ کامل است و بالا و پایین کپی بلورشدهٔ برعکس‌شده و کم‌نورِ سیاه‌وسفید است. تیتر در این حالت درشت‌تر است. ربات ویدیو را با نشان «ذره‌بین»، تیتر و واترمارک برمی‌گرداند.

## ساختار
- `template/index.html` قالب تیتر و واترمارک (فونت آبر MidBlack ۴۸٫۵، فاصله خط ۷۹٫۸، وسط‌چین؛ واترمارک Lato Bold)
- `assets/badge.mov` نشان متحرک (فایل خودت، شفاف) که با طول ویدیو تنظیم می‌شود
- `render_overlay.mjs` رندر شفاف تیتر + واترمارک
- `compose.py` ترکیب روی ویدیو (نشان از ثانیهٔ ۰، ماندن، جمع‌شدن ۵٫۳ ثانیه مانده به پایان، پخش دوباره)
- `bot.py` ربات تلگرام؛ `.github/workflows/bot.yml` اجرا روی GitHub Actions هر ۵ دقیقه

## راه‌اندازی (بعد از تأیید قالب)
1. در تلگرام با @BotFather یک ربات **جدید** بساز و توکن را نگه دار (ربات tg2yt را دوباره استفاده نکن).
2. یک ریپوی خصوصی در GitHub بساز و این پوشه را در آن آپلود کن.
3. Settings › Secrets and variables › Actions: `BOT_TOKEN` را اضافه کن. `ALLOWED_CHAT_IDS` را بعد از اولین پیام به ربات اضافه کن (ربات شناسهٔ چتت را می‌گوید).
4. Actions › zarrebin-bot › Run workflow.

محدودیت‌ها: ویدیوی ورودی حداکثر ۲۰ مگابایت، خروجی حداکثر ۵۰ مگابایت (محدودیت تلگرام). پاسخ بین ۵ تا ۱۵ دقیقه طول می‌کشد.
